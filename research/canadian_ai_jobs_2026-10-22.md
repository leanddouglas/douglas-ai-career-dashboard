# Canadian applied-AI job evidence — 22 October 2026

## Bottom line

The collected postings support **applied AI as a software/integration/operations career, not a prompt-only occupation**. The most plausible lower-credential opening in this evidence set is Vexio's portfolio-oriented automation builder role, but it is a first technical hire in Lethbridge with substantial independent responsibility and compensation caveats—not a safe equivalent to a mentored junior developer job. The clearly junior and intern roles are credential-gated.

This is a **purposive, illustrative cross-section**, not a statistically representative labour-market survey. Searches covered the six requested title families and employer-equivalent roles, prioritizing BC and remote Canada. Twelve distinct accessible postings across nine employers are included: eleven have live employer-page/ATS evidence, and one (Vexio) is an accessible reputable-board posting without independent employer confirmation. Search snippets alone were not accepted. Expired and inaccessible leads are listed separately. No applications were submitted and no employers were contacted. Retrieval date was verified locally as 2026-10-22 PDT.

**Status limitations:** Accessible/apply-enabled does not prove an employer is actively interviewing. Older first-publication dates are retained rather than presented as new jobs. Oyster's body allows AMER/EMEA and Built In specifies remote Canada, but its ATS main location says EMEA; confirm Canadian hiring. MCI's nationwide label does not establish work-from-home eligibility. AMD's job body is accessible through extraction and employer HTML, but browser access returned 403; salary metadata is conflicting.

- 1/12 has no stated credential or numeric years minimum and explicitly requests a project link/video: Vexio J03. This does not make its founding-hire scope entry level.
- 9/12 are experienced/senior-scope: J04–J12. Six explicitly use **Senior** in their title. AMD asks for a seasoned lead; Coalition's unsuffixed Software Engineer still asks for 5+ years.
- 7/12 state a numeric minimum of at least three years of relevant professional experience (J04, J05, J08–J12). Field-service tenure cannot automatically be substituted for those software/AI years.
- 5/12 list a completed bachelor's/master's qualification (J01, J04, J06, J10, J11); 1/12 requires current degree enrolment (J02); 6/12 do not state a credential requirement. J11 places its degree under “Qualifications We Value,” not an explicit minimum heading. None of the six omitted-credential listings proves that education will be ignored in screening.
- 3/12 explicitly offer a BC location (J05–J07); another 5/12 offer remote Canada or Canada-inclusive AMER remote work (J08–J12, with the Oyster caveat). MCI is nationwide but remote status is unspecified.
- Python appears in 9/12, counting language alternatives and preferred/bonus mentions—not nine universal hard Python requirements. The distinction matters: Oyster lists coding languages as a bonus; Ericsson/Cresta intern accept another language.

The counts weight postings, not employers; Cresta contributes three and Coalition two. They should not be projected into Canadian hiring probabilities, market-wide degree percentages, vacancy totals, or salary averages.

## Recurring qualifications and implications for Douglas

1. **Software foundations still matter.** Python, another general-purpose language, APIs, data handling, Git, debugging and maintainable software recur. Cresta's backend integration role requires distributed/real-time systems and production APIs; knowing how to operate an agent is not equivalent to this engineering experience. [J01, J02, J04, J06, J08–J11]
2. **The differentiator is reliable delivery, not a chatbot demo.** Employers ask for evaluations, test sets, monitoring, permissions, human review, auditability, rollback, security, deployment and support. Coalition explicitly requires an agent non-engineers depend on; Unblocked contrasts production apps with notebook prototypes. [J04, J07–J11]
3. **Business-process translation is central.** Requirements gathering, communicating with nontechnical users, adoption, documentation, measurable time/quality improvement and domain knowledge recur. Douglas's field-service and LMS context can contribute relevant domain evidence, but does not replace specified software-engineering experience. [J03–J06, J08–J12]
4. **Platform skills complement coding.** n8n/Make/Zapier, LLM APIs, agent tools/MCP, RAG, cloud and containers appear in different combinations. Not every employer requires every framework. Vexio directly values n8n and independent code debugging; Oyster's GTM specialization requires much more than building an isolated automation. [J03, J04, J06–J12]
5. **Education has two different benefits here.** It can provide transferable software fundamentals and it can unlock explicitly degree/enrolment-gated junior/intern channels. A short AI-tools certificate is not shown by this sample to replace either. AMD mentions relevant certifications only as preferred; no included role explicitly requires an AI-specific certificate. This is an inference about curriculum fit, not a comparison of schools or evidence of placement outcomes.
6. **Portfolio route is real but not easy.** Six listings omit credentials, yet most demand substantial shipped work. Existing Hermes/Ollama/Python/API/GitHub/web/LMS projects are candidate portfolio material, not proof of independent mastery. A useful portfolio would explain the business problem, Douglas's own implementation contribution, code he can debug without relying blindly on agents, tests/evals, data/privacy decisions, deployment and incident recovery, and measured user outcomes. Vexio explicitly requests a demo/link; Cresta senior uses a coding assessment. [J03, J07–J12]

For an education decision, favour a pathway that teaches programming, data/SQL, API/web development, testing, source control, security and deployment, with applied-AI projects and credible work experience. Investigate adult-upgrading/admission requirements separately: this posting research does not establish Douglas's eligibility for any program, nor does a missing job-posting credential line establish that high-school completion is unnecessary.
